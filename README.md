## 便宜在哪，贵在哪

**首月5折是拉新价，不是长期价。** 通过推广链接注册并绑定微信，系统自动发一张首月5折券，30天有效，云服务器、游戏云、虚拟主机基本都能用，不用手动填优惠码。第二个月起恢复原价，想继续省只能走季付9折、半年8折、年付7折。

**首月5折和年付7折能不能叠加，网上两种说法都有。** 有的文章写不能叠加，建议先用5折买一个月再转年付；有的写能叠加，还给出“20×12×0.7再首月5折”的算法。这两种说法不能同时成立，实际操作时看券面说明有没有写“可与长期折扣叠加”，没写就不要按叠加价做预算。最稳的做法是首月5折试用，确认机房延迟和性能没问题，续费时再选年付。

**第一年到底花多少，算三个例子：**

- EPYC 1核1G：全程年付7折168元；全程月付、首月5折230元。差62元。
- 游戏云9950X 2核4G：年付940.8元；月付首月56元加后11个月112元，共1288元。差347元。
- 虚拟主机入门版：年付67.2元；月付首月4元加后11个月8元，共92元。差24.8元。

配置越高，年付和月付的绝对差额越大。长期用的机器，第二个月转年付比一直月付划算。

**独立IP是容易被漏算的一笔。** 默认给共享IP，用NAT端口映射，建站需要80/443端口时可能受限。高防IP常见30元/月起，深圳20G高防和宁波100G高防都是这个价，十堰约50元/月；普通独立IP更便宜，香港、洛杉矶有过5元/月的口径。网上流传的“江苏单IP 150元/月”是2023年的说法，更像高防IP的报价，不要拿来估算现在的建站成本。真要用独立IP建站，一年360元起，比18元的套餐本身贵得多。

**消费返积分能抵一点。** 基础用户返10%，I级12%，II级15%，III级20%，积分可换优惠券、虚拟主机额度、CDN流量包或直接抵扣。返的是积分，不是现金，别把它当成直接打折。

## 下单前要知道的坑

- **国内节点要备案**：宿迁、宁波、十堰、襄阳、广州、深圳这些节点，域名必须完成ICP备案才能绑定，流程约20天。不想等只能选香港或美国。
- **共享IP的端口限制**：默认NAT共享IP，80/443可能不能用，建站前确认是否需要加购独立IP。
- **不限流量≠随便跑满**：公平使用原则写在条款里，长期占满带宽会被限速。
- **动态计费在高负载下更贵**：游戏云基础价低，CPU长期高负载会按0.001元/电量加收，长期80%以上占用可能反超固定计费。低负载、白天没人晚上爆满的私服更适合这种模式。
- **退款只退余额**：7天无理由退款一般限3次，退到账户余额，不能提现到支付宝或微信。
- **工单响应分时段**：通常几小时内回复，节假日或半夜可能拖到第二天，紧急情况进QQ群更快。
- **线路有差异**：宿迁、宁波电信体验最好，联通、移动有时绕路；洛杉矶晚高峰可能拥堵。
- **稳定性较大厂有差距**：早期有过网络波动和母鸡维护导致的临时下线，近期抱怨少了，但电商、支付这类关键业务仍不建议放在小厂。

## 常见问题

**雨云服务器能备案吗？**
国内节点可以，域名完成ICP备案后绑定，约20天。香港、日本、洛杉矶节点免备案。

**续费会涨价吗？**
月付价本身稳定，首月5折只作用于首月。长期成本靠年付7折锁定，续费时选年付比一直月付便宜30%。

**1核1G能干什么？**
个人博客、静态站、轻量代理、测试环境。装宝塔加MySQL、跑Docker多容器会吃紧，建议2核2G起步。

**游戏云和普通云服务器差在哪？**
游戏云用9950X、14900K这类高频消费级CPU，带MCSM面板和一键开服，计费含动态电量费；普通云服务器用EPYC或Xeon，适合通用业务。

**能退款吗？**
7天无理由，一般限3次，退到账户余额，不能提现。
